# UI Reskin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Overhaul the desktop app to a warm amber/gold editorial aesthetic with album artwork displayed throughout — sidebar thumbnails, 2×2 mosaic playlist headers, and per-track art.

**Architecture:** Backend gains `artwork_url` storage on tracks (populated during pre-flight sync) and a `thumbnail_url` field on the playlists endpoint. Frontend gains CSS design tokens in `app.css`, then each component is reskinned from Spotify-green/dark-grey to amber-on-near-black with artwork rendered via Apple Music CDN URLs.

**Tech Stack:** Python/FastAPI backend, Svelte 5 + Tailwind CSS frontend, SQLite state, Tauri desktop shell.

function thumbUrl(url: string | null | undefined, size: string): string {
  if (!url) return "";

// First 4 distinct artwork URLs for the mosaic header
let mosaicArts = $derived(() => {
  const seen = new Set<string>();
  const result: (string | null)[] = [];
  for (const t of tracks) {

});
